# claude-inlineDiff
VsCode插件
Trae 风格的 Claude Code 行内改动审查：vscode的Claude code插件 在 auto 模式下改完代码后不会高亮显示修改内容，本工具实现在编辑器中集中标出新增、修改与删除，支持一次性审核和逐条确认。

## 功能

- **改动高亮**：新增行显示绿色整行背景与词级高亮；修改行同样按新增展示，并标注被替换的旧内容。
- **实时识别**：直接监听 Claude 会话记录与工作区文件变化，Claude 一写入改动就会刷新，不再依赖轮询间隔；通过 shell 命令/脚本产生的改动也会被识别。
- **工作区外文件**：Claude 修改当前工作区之外的文件（例如全局配置、其他目录下的项目）同样会在审查面板中列出，并以绝对路径或 `~` 路径显示。
- **删除标记**：在删除接缝处显示红色箭头和删除行数，悬停可查看被删内容。
- **单栏内联审查**：在同一列中展示红色删除行与绿色新增行，不使用 Split Diff。
- **就地审核**：逐处或按文件标记已审核，只更新插件内部基线，不修改源码。
- **拒绝/还原**：按单处、单文件或全部还原到 Claude 修改前的内容；新建文件删除、被删除的文件恢复，执行前有确认提示。
- **只显示需要审核的改动**：只有在存在尚未审核的 Claude 改动时才会列出 diff。此时手动修改、`git reset --hard` 等外部改动会一并并入审查；没有待审核的 Claude 改动时，任何外部改动都不会被记录。
- **回滚自动撤回**：在 Claude Code 内回滚代码时，被恢复到历史快照的文件会自动撤回对应的改动记录，而不会被当成新的 Claude 改动重新列出。
- **会话跟踪**：自动绑定本窗口的 Claude Code 会话，支持按整个会话或单轮计算基线，审核状态跨重启保留。
- **纯本地**：只读本地会话与文件快照，不访问网络。

受 VS Code 扩展 API 限制，真实编辑器无法插入多行虚拟删除文本，完整删除内容需在单栏内联审查视图中查看。
