# Claude Inline Diff

Trae 风格的 Claude Code 行内改动审查：Claude 在 auto 模式下批量改完代码后，在编辑器中集中标出新增、修改与删除，一次性审核，而不是逐条确认。

## 功能

- **纯新增**：绿色整行背景、词级高亮、行号左侧固定绿色竖线。
- **修改**（删旧增新）：保留绿色整行背景，竖线改为麻蓝色斜纹，与纯新增区分。
- **纯删除**：不使用竖线，在删除接缝处显示红色箭头和删除行数，悬停可查看被删内容。
- **单栏内联审查**：在同一列中展示红色删除整行与绿色新增整行，不使用 Split Diff。
- **就地审核**：只更新插件内部的审核基线，不修改源码；已审核的改动立即取消高亮和删除标记。
- **会话跟踪**：自动跟随最近的 Claude Code 会话，支持按整个会话或单轮计算基线，审核状态跨重启保留。
- **纯本地**：只读 Claude Code 会话与文件快照，不访问网络。

受 VS Code 扩展 API 限制，真实编辑器无法插入多行虚拟删除文本，完整删除内容需在单栏内联审查视图中查看。
